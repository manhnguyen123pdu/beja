1. Tổng quan về Refresh Token

Trong cơ chế xác thực bằng JWT, Access Token thường được sử dụng để xác thực người dùng khi gọi API. Tuy nhiên, Access Token không nên có thời gian sống quá dài vì nếu bị lộ, người khác có thể sử dụng nó trong khoảng thời gian token còn hiệu lực.

Để giải quyết vấn đề này, hệ thống sử dụng thêm Refresh Token.

Mô hình cơ bản:

User
 │
 │ Login
 ▼
Server
 │
 ├── Access Token
 │
 └── Refresh Token

Khi Access Token hết hạn:

Access Token hết hạn
        │
        ▼
Client gửi Refresh Token
        │
        ▼
Server kiểm tra Refresh Token
        │
        ▼
Tạo Access Token mới
        │
        ▼
Client tiếp tục gọi API

1.1. Refresh Token là gì?

Refresh Token là một loại token được sử dụng để xin cấp Access Token mới khi Access Token hiện tại đã hết hạn.

Refresh Token không được sử dụng để truy cập trực tiếp vào các API nghiệp vụ.

Ví dụ:

Access Token:
    Dùng để → gọi API

Refresh Token:
    Dùng để → xin Access Token mới

Có thể hình dung:

Access Token = vé sử dụng API
Refresh Token = giấy phép xin cấp lại vé mới

Ví dụ

Khi người dùng đăng nhập:

POST /api/auth/login
POST /api/auth/login

Server có thể trả về:

Response
{
    "accessToken": "eyJhbGciOiJIUzI1NiJ9...",
    "refreshToken": "eyJhbGciOiJIUzI1NiJ9..."
}

Client sử dụng:

accessToken

để gọi:

GET /api/users
GET /api/products
GET /api/orders

Sau một khoảng thời gian, Access Token hết hạn.

Thay vì bắt người dùng đăng nhập lại, client gửi:

POST /api/auth/refresh
POST /api/auth/refresh

kèm theo Refresh Token.

Server kiểm tra Refresh Token và nếu hợp lệ thì tạo:

Access Token mới

1.3. Tại sao cần Refresh Token?

Nếu hệ thống chỉ sử dụng Access Token thì có một vấn đề.

Giả sử Access Token có thời gian sống:

2 giờ

Nếu token bị đánh cắp, kẻ tấn công có thể sử dụng token đó trong tối đa 2 giờ.

Do đó, ta muốn Access Token có thời gian sống ngắn.

Ví dụ:

Access Token = 15 phút

Nhưng nếu Access Token chỉ sống 15 phút thì người dùng sẽ phải đăng nhập lại liên tục:

Login
  ↓
Access Token
  ↓
15 phút
  ↓
Hết hạn
  ↓
Đăng nhập lại
  ↓
Access Token mới
  ↓
15 phút
  ↓
Hết hạn
  ↓
Đăng nhập lại

Điều này gây trải nghiệm rất khó chịu.

Refresh Token giải quyết vấn đề này

Thay vì:

Người dùng không cần nhập username/password lại.

2.5. Tạo Refresh Token

Sau khi tạo Access Token, hệ thống tạo thêm Refresh Token.

Ở các bài trước trong JwtService đã có :

JwtService
public String generateToken(UserDetails userDetails) {
    return Jwts.builder()
        .subject(userDetails.getUsername())
        .claim(
                "role",
                userDetails.getAuthorities().stream().findFirst()
                        .map(GrantedAuthority::getAuthority).orElse("")
        )
        .claim("type", "access")
        .issuedAt(new Date())
        .expiration(new Date(System.currentTimeMillis() + expiration))
        .signWith(getKey())
        .compact();
}

Đây là Access Token:

JwtService
.claim("type", "access")

Sau đó tạo phương thức riêng cho Refresh Token:

Java
 public String generateRefreshToken(UserDetails userDetails) {
    return Jwts.builder()
        .subject(userDetails.getUsername())
        .claim("type", "refresh")
        .issuedAt(new Date())
        .expiration(new Date(System.currentTimeMillis() + refreshExpiration))
        .signWith(getKey())
        .compact();
}

Điểm khác biệt quan trọng:

Java
.claim("type", "access")

so với:

Java
.claim("type", "refresh")

và thời gian hết hạn:

accessExpiration

so với:

refreshExpiration

4.11. Code AuthService

Java

@Service
@RequiredArgsConstructor
public class AuthService {

    private final AuthenticationManager authenticationManager;

    private final JwtService jwtService;
    private final RefreshTokenService refreshTokenService;
    private final CustomUserDetailsService userDetailsService;

    public LoginResponse login(LoginRequest request) {

        Authentication authentication = authenticationManager.authenticate(new UsernamePasswordAuthenticationToken(request.getUsername(), request.getPassword()));

        UserDetails userDetails = (UserDetails) authentication.getPrincipal();


        // Access Token
        String accessToken = jwtService.generateToken(userDetails);


        // Refresh Token
        String refreshToken = jwtService.generateRefreshToken(userDetails);


        // Lưu Refresh Token vào DB
        refreshTokenService.save(refreshToken, userDetails.getUsername());


        return new LoginResponse(accessToken, refreshToken);
    }

    public LoginResponse refreshToken(RefreshTokenRequest request) {

        String token = request.getRefreshToken();


        // 1. Tìm token trong DB
        RefreshToken refreshToken = refreshTokenService.findByToken(token);


        // 2. Kiểm tra hết hạn
        refreshTokenService.verifyExpiration(refreshToken);


        // 3. Lấy username
        String username = refreshToken.getUsername();


        // 4. Load UserDetails
        UserDetails userDetails = userDetailsService.loadUserByUsername(username);


        // 5. Tạo Access Token mới
        String accessToken = jwtService.generateToken(userDetails);


        // 6. Trả response
        return new LoginResponse(accessToken, token);
    }
}

5. Refresh Token Rotation

5.1. Refresh Token Rotation là gì?

Refresh Token Rotation là cơ chế trong đó mỗi lần Client sử dụng Refresh Token để lấy Access Token mới, hệ thống sẽ tạo ra một Refresh Token mới và vô hiệu hóa Refresh Token cũ.

Ví dụ ban đầu Client đang có:

Refresh Token A

Client gửi Token A đến:

HTTP
POST /api/auth/refresh

Server sẽ:

  1. Kiểm tra Refresh Token A.
  2. Tạo Access Token mới.
  3. Tạo Refresh Token B.
  4. Vô hiệu hóa Refresh Token A.
  5. Lưu Refresh Token B vào Database.
  6. Trả Access Token mới và Refresh Token B cho Client.

Kết quả:

Refresh Token A
      │
      ▼
   /refresh
      │
      ├── Access Token mới
      │
      └── Refresh Token B

Trong đó:

Token A → revoked = true
Token B → revoked = false

5.2. Tại sao cần Rotation?

Refresh Token thường có thời gian sống dài hơn Access Token.

Ví dụ:

Access Token  → 15 phút
Refresh Token → 7 ngày

Nếu Refresh Token bị đánh cắp, attacker có thể sử dụng nó để liên tục tạo Access Token mới.

Ví dụ nếu không có Rotation:

Refresh Token A
      │
      ├── /refresh → Access Token B
      │
      ├── /refresh → Access Token C
      │
      ├── /refresh → Access Token D
      │
      └── /refresh → Access Token E

Token A vẫn có thể được sử dụng nhiều lần.

Với Rotation:

Refresh Token A
      │
      ▼
   /refresh
      │
      ▼
Refresh Token B

Sau đó:

Token A → ❌ revoked
Token B → ✅ active

Nếu tiếp tục Refresh:

Refresh Token B
      │
      ▼
   /refresh
      │
      ▼
Refresh Token C

Kết quả:

A → ❌ revoked
B → ❌ revoked
C → ✅ active

Như vậy mỗi Refresh Token chỉ được sử dụng trong một lần Rotation.

5.3. Mỗi lần Refresh tạo Refresh Token mới

Ở cơ chế Refresh Token cơ bản trước đó, chúng ta có:

Java
return new LoginResponse(accessToken, token);

Tức là sau khi Refresh:

Request:
Refresh Token A

Response:
Access Token B
Refresh Token A

Refresh Token A vẫn được trả lại cho Client.

Điều này không phải Rotation.

Với Rotation, chúng ta phải tạo Refresh Token mới:

Java
String newRefreshToken =
        jwtService.generateRefreshToken(userDetails);

Sau đó lưu Token mới:

Java
refreshTokenService.save(
        newRefreshToken,
        userDetails.getUsername()
);

Cuối cùng trả Token mới về Client:

Java
return new LoginResponse(
        accessToken,
        newRefreshToken
);

5.4. Vô hiệu hóa Refresh Token cũ

Đây là bước quan trọng nhất của Rotation.

Bạn đã có trường:

Java
private boolean revoked = false;

Trong Database:

revoked = 0

có nghĩa:

false
→ Token chưa bị vô hiệu hóa

Khi Token được sử dụng để Rotation:

Java
refreshToken.setRevoked(true);

Database sẽ lưu:

revoked = 1

Có nghĩa:

true
→ Token đã bị vô hiệu hóa

Ví dụ trước Rotation:

┌────┬───────┬──────────┐
│ id │ token │ revoked  │
├────┼───────┼──────────┤
│ 1  │ A     │ 0        │
└────┴───────┴──────────┘

Sau Rotation:

┌────┬───────┬──────────┐
│ id │ token │ revoked  │
├────┼───────┼──────────┤
│ 1  │ A     │ 1        │
│ 2  │ B     │ 0        │
└────┴───────┴──────────┘

Token A không bị xóa khỏi Database.

Nó được giữ lại với:

revoked = true

Điều này rất quan trọng cho phần tiếp theo Refresh Token Reuse Detection, bởi vì nếu Token A được gửi lại, hệ thống có thể phát hiện:

revoked = true
       ↓
Token đã bị sử dụng lại
       ↓
REUSE DETECTION

Ví dụ đầy đủ phần liên quan:

Java
@Service
@RequiredArgsConstructor
public class RefreshTokenService {

    private final RefreshTokenRepository refreshTokenRepository;

    @Value("${jwt.refresh-expiration}")
    private long refreshExpiration;

    // Lưu Refresh Token
    public RefreshToken save(String token, String username) {

        RefreshToken refreshToken = new RefreshToken();

        refreshToken.setToken(token);
        refreshToken.setUsername(username);

        refreshToken.setExpiryDate(
                LocalDateTime.now()
                        .plusSeconds(refreshExpiration / 1000)
        );

        return refreshTokenRepository.save(refreshToken);
    }

    // Tìm Refresh Token
    public RefreshToken findByToken(String token) {

        return refreshTokenRepository
                .findByToken(token)
                .orElseThrow(() ->
                        new RuntimeException(
                                "Refresh token not found"
                        )
                );
    }

    // Kiểm tra hết hạn
    public void verifyExpiration(
            RefreshToken refreshToken) {

        if (refreshToken.getExpiryDate()
                .isBefore(LocalDateTime.now())) {

            throw new RuntimeException(
                    "Refresh token expired"
            );
        }
    }

    // Vô hiệu hóa Refresh Token
    public RefreshToken revoke(
            RefreshToken refreshToken) {

        refreshToken.setRevoked(true);

        return refreshTokenRepository.save(refreshToken);
    }
}

Ở đây không xóa Token cũ. Chúng ta chỉ chuyển revoked từ false → true.

Phương thức refreshToken() sẽ trở thành:

        RefreshTokenRequest request) {

    // 1. Lấy Refresh Token từ request
    String token = request.getRefreshToken();

    // 2. Tìm Refresh Token trong DB

    String newRefreshToken =
            jwtService.generateRefreshToken(userDetails);

    refreshTokenService.revoke(refreshToken);

    // 10. Lưu Refresh Token mới
    refreshTokenService.save(
            newRefreshToken,
            userDetails.getUsername()
    );

    // 11. Trả Token mới cho Client
    return new LoginResponse(
            accessToken,
            newRefreshToken
    );
}

6. Refresh Token Reuse Detection

6.1. Reuse Refresh Token là gì?

Refresh Token Reuse xảy ra khi một Refresh Token đã bị vô hiệu hóa nhưng vẫn tiếp tục được sử dụng để gọi API /refresh.

Ví dụ:

Refresh Token A
      │
      ▼
   /refresh
      │
      ▼
Token A được sử dụng
      │
      ├──► Token A → revoked = true
      │
      └──► Cấp Refresh Token B

Sau đó Client hợp lệ tiếp tục sử dụng:

Refresh Token B

Nhưng một kẻ tấn công trước đó đã đánh cắp:

Refresh Token A

và vẫn giữ Token A.

Nếu attacker gửi Token A lần nữa:

Refresh Token A
      │
      ▼
   /refresh
      │
      ▼
Token A tồn tại trong DB
      │
      ▼
revoked = true
      │
      ▼
⚠️ REUSE DETECTED

Đây chính là hành vi Refresh Token Reuse.

6.2. Refresh Token bị đánh cắp có thể gây nguy hiểm như thế nào?

Refresh Token thường có thời gian sống dài hơn Access Token.

Ví dụ:

Access Token  → 15 phút
Refresh Token → 7 ngày

Nếu attacker đánh cắp Refresh Token A:

Attacker
   │
   └── Refresh Token A
             │
             ▼
          /refresh
             │
             ▼
       Access Token mới

Nếu hệ thống không có Rotation và Reuse Detection, attacker có thể tiếp tục sử dụng Refresh Token đó để lấy Access Token mới.

Vì vậy Refresh Token bị đánh cắp có thể dẫn đến việc attacker duy trì quyền truy cập lâu hơn thời gian sống của một Access Token.

7. Token Family

7.1. Token Family là gì?

Ở phần Refresh Token Rotation, ta có cơ chế:

Refresh Token A
      │
      ▼
   /refresh
      │
      ▼
A bị revoke
      │
      ▼
Tạo Refresh Token B

Tiếp tục:

B → C → D → E

Như vậy các Refresh Token này có cùng nguồn gốc:

A → B → C → D

Các token này thuộc cùng một Token Family.

Token Family là nhóm các Refresh Token được sinh ra trong cùng một phiên đăng nhập thông qua quá trình Refresh Token Rotation.

Ví dụ:

Token Family A

  ↓
RT-B
  ↓
RT-C
  ↓
RT-D

Tất cả:

RT-A
RT-B
RT-C
RT-D

đều thuộc:

Family A

7.2. Tại sao cần Token Family?

Ở phần Reuse Detection, ta có tình huống:

RT-A → RT-B → RT-C

Trong đó:

RT-A = revoked
RT-B = revoked
RT-C = active

Sau đó attacker lấy được RT-A và sử dụng lại:

Attacker
    │
    ▼
  RT-A
    │
    ▼
Đã revoked?
    │
   YES
    │
    ▼
REUSE DETECTED

Server phát hiện token cũ bị sử dụng lại.

Nếu chỉ vô hiệu hóa:

thì chưa đủ.

Vì attacker có thể đã chiếm được quyền sử dụng cả phiên đó.

public LoginResponse refreshToken(RefreshTokenRequest request) {

    String token = request.getRefreshToken();

    // 1. Tìm Refresh Token trong DB
    RefreshToken refreshToken =
            refreshTokenService.findByToken(token);


    // 2. Kiểm tra Reuse
    if (refreshToken.isRevoked()) {

        String familyId =
                refreshToken.getFamilyId();

        // Reuse detected
        refreshTokenService.revokeFamily(familyId);

        throw new RuntimeException(
                "Refresh token reuse detected"
        );
    }
    
    // 3. Kiểm tra hết hạn
    refreshTokenService.verifyExpiration(refreshToken);

    // 4. Lấy Family hiện tại
    String familyId =
            refreshToken.getFamilyId();

    // 5. Lấy User
    String username =
            refreshToken.getUsername();

    UserDetails userDetails =
            userDetailsService.loadUserByUsername(username);

    // 6. Tạo Access Token mới
    String accessToken =
            jwtService.generateToken(userDetails);

    // 7. Tạo Refresh Token mới
    String newRefreshToken =
            jwtService.generateRefreshToken(userDetails);

    // 8. Revoke Refresh Token cũ
    refreshTokenService.revoke(refreshToken);

    // 9. Lưu Refresh Token mới
    //    nhưng GIỮ NGUYÊN familyId
    refreshTokenService.save(
            newRefreshToken,
            userDetails.getUsername(),
            familyId
    );

    // 10. Trả response
    return new LoginResponse(
            accessToken,
            newRefreshToken
    );
}

7.16. RefreshTokenService hoàn chỉnh

Sau khi thêm Token Family, Service của bạn sẽ thành:

Java
@Service
@RequiredArgsConstructor
public class RefreshTokenService {

    private final RefreshTokenRepository refreshTokenRepository;

    @Value("${jwt.refresh-expiration}")
    private long refreshExpiration;


    // LƯU REFRESH TOKEN
    public RefreshToken save(
            String token,
            String username,
            String familyId
    ) {

        RefreshToken refreshToken =
                new RefreshToken();

        refreshToken.setToken(token);
        refreshToken.setUsername(username);

        // Lưu Family
        refreshToken.setFamilyId(familyId);

        refreshToken.setExpiryDate(
                LocalDateTime.now()
                        .plusSeconds(
                                refreshExpiration / 1000
                        )
        );

        return refreshTokenRepository.save(
                refreshToken
        );
    }


    // TÌM REFRESH TOKEN
    public RefreshToken findByToken(String token) {

        return refreshTokenRepository
                .findByToken(token)
                .orElseThrow(() ->
                        new RuntimeException(
                                "Refresh token not found"
                        )
                );
    }


    // KIỂM TRA EXPIRATION
    public void verifyExpiration(RefreshToken refreshToken) {
        if (refreshToken.getExpiryDate().isBefore(LocalDateTime.now())) {
            throw new RuntimeException("Refresh token expired");
        }
    }


    // REVOKE 1 TOKEN
    public RefreshToken revoke(RefreshToken refreshToken) {
        refreshToken.setRevoked(true);
        return refreshTokenRepository.save(refreshToken);
    }


    // REVOKE TOÀN BỘ TOKEN TRONG FAMILY
    public void revokeFamily(String familyId) {

        List<RefreshToken> tokens =
                refreshTokenRepository
                        .findByFamilyId(familyId);

        tokens.forEach(token ->
                token.setRevoked(true)
        );

        refreshTokenRepository.saveAll(tokens);
    }
}

import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.oauth2.jwt.JwtDecoder;
import org.springframework.security.oauth2.jwt.NimbusJwtDecoder;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationConverter;
import org.springframework.security.oauth2.server.resource.authentication.JwtGrantedAuthoritiesConverter;
import org.springframework.security.web.SecurityFilterChain;

import javax.crypto.SecretKey;

@Configuration
@EnableWebSecurity
@RequiredArgsConstructor
public class SecurityConfig {

    @Value("${jwt.secret-key}")
    private String secretKeyValue;

    @Bean
    public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
        http.csrf(csrf -> csrf.disable())
                .sessionManagement(session ->
                        session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
                .authorizeHttpRequests(auth -> auth
                        .requestMatchers("/api/auth/signIn").permitAll()
                        .requestMatchers("/api/auth/login").permitAll()
                        .requestMatchers("/api/auth/refresh").permitAll()
                        .requestMatchers("/api/demo/public").permitAll()
                        .requestMatchers("/api/demo/user").hasRole("USER")
                        .requestMatchers("/api/demo/admin").hasRole("ADMIN")
                        .anyRequest().authenticated())
                .oauth2ResourceServer(oauth2 ->
                        oauth2.jwt(jwt ->
                                jwt.jwtAuthenticationConverter(jwtAuthenticationConverter())
                        )
                )
                .httpBasic(httpBasic -> httpBasic.disable());

        return http.build();
    }

    @Bean
    public JwtAuthenticationConverter jwtAuthenticationConverter() {
        JwtGrantedAuthoritiesConverter converter = new JwtGrantedAuthoritiesConverter();
        converter.setAuthoritiesClaimName("role");
        converter.setAuthorityPrefix("");

        JwtAuthenticationConverter jwtConverter = new JwtAuthenticationConverter();
        jwtConverter.setJwtGrantedAuthoritiesConverter(converter);

        return jwtConverter;
    }

    @Bean
    public JwtDecoder jwtDecoder() {
        SecretKey secretKey = Keys.hmacShaKeyFor(Decoders.BASE64.decode(secretKeyValue));
        return NimbusJwtDecoder.withSecretKey(secretKey).build();
    }

    @Bean
    public AuthenticationManager authenticationManager(
            AuthenticationConfiguration configuration) throws Exception {
        return configuration.getAuthenticationManager();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }
}

import org.springframework.http.ResponseEntity;
import org.springframework.security.core.userdetails.UsernameNotFoundException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

import java.util.HashMap;
import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(UsernameNotFoundException.class)
    public ResponseEntity<ApiResponse<Void>> handleUsernameNotFoundException(
            UsernameNotFoundException e) {

        ApiResponse<Void> apiResponse = new ApiResponse<>(
                404,
                e.getMessage(),
                null
        );
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(apiResponse);
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ResponseEntity<ApiResponse<Map<String, String>>>
    handleValidationException(MethodArgumentNotValidException ex) {

        Map<String, String> errors = new HashMap<>();

        ex.getBindingResult()
                .getFieldErrors()
                .forEach(error ->
                        errors.put(
                                error.getField(),
                                error.getDefaultMessage()
                        )
                );

        ApiResponse<Map<String, String>> response =
                new ApiResponse<>(
                        400,
                        "Validation failed",
                        errors
                );

        return ResponseEntity
                .status(HttpStatus.BAD_REQUEST)
                .body(response);
    }
}

package com.example.security.service;

import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.io.Decoders;
import io.jsonwebtoken.security.Keys;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.security.core.GrantedAuthority;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.stereotype.Service;

import javax.crypto.SecretKey;
import java.util.Date;

@Service
public class JwtService {

    @Value("${jwt.secret-key}")
    private String secretKey;

    @Value("${jwt.expiration}")
    private long expiration;

    @Value("${jwt.refresh-expiration}")
    private long refreshExpiration;

    // ==========================
    // ACCESS TOKEN
    // ==========================
    public String generateToken(UserDetails userDetails) {
        return Jwts.builder()
                .subject(userDetails.getUsername())
                .claim(
                        "role",
                        userDetails.getAuthorities().stream().findFirst()
                                .map(GrantedAuthority::getAuthority).orElse("")
                )
                .claim("type", "access")
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + expiration))
                .signWith(getKey())
                .compact();
    }

    // ==========================
    // REFRESH TOKEN
    // ==========================
    public String generateRefreshToken(UserDetails userDetails) {
        return Jwts.builder()
                .subject(userDetails.getUsername())
                .claim("type", "refresh")
                .issuedAt(new Date())
                .expiration(new Date(System.currentTimeMillis() + refreshExpiration))
                .signWith(getKey())
                .compact();
    }

    // ==========================
    // SECRET KEY
    // ==========================
    private SecretKey getKey() {
        return Keys.hmacShaKeyFor(
                Decoders.BASE64.decode(secretKey)
        );
    }
}

package com.example.security.service;

import com.example.security.entity.RefreshToken;
import com.example.security.repository.RefreshTokenRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

import java.time.LocalDateTime;
import java.util.List;

@Service
@RequiredArgsConstructor
public class RefreshTokenService {

    private final RefreshTokenRepository refreshTokenRepository;

    @Value("${jwt.refresh-expiration}")
    private long refreshExpiration;

    // ==========================
    // LƯU REFRESH TOKEN VÀO DB
    // ==========================
    public RefreshToken save(String token, String username, String familyId) {
        RefreshToken refreshToken = new RefreshToken();

        refreshToken.setToken(token);
        refreshToken.setUsername(username);
        refreshToken.setFamilyId(familyId);
        refreshToken.setExpiryDate(
                LocalDateTime.now().plusSeconds(refreshExpiration / 1000)
        );

        return refreshTokenRepository.save(refreshToken);
    }

    // ==========================
    // TÌM REFRESH TOKEN
    // ==========================
    public RefreshToken findByToken(String token) {
        return refreshTokenRepository
                .findByToken(token)
                .orElseThrow(() ->
                        new RuntimeException("Refresh token not found"));
    }

    // ==========================
    // KIỂM TRA HẾT HẠN
    // (KHÔNG xóa token để giữ Reuse Detection)
    // ==========================
    public void verifyExpiration(RefreshToken refreshToken) {
        if (refreshToken.getExpiryDate().isBefore(LocalDateTime.now())) {
            throw new RuntimeException("Refresh token expired");
        }
    }

    // ==========================
    // REVOKE 1 TOKEN
    // ==========================
    public RefreshToken revoke(RefreshToken refreshToken) {
        refreshToken.setRevoked(true);
        return refreshTokenRepository.save(refreshToken);
    }

    // ==========================
    // REVOKE TOÀN BỘ TOKEN TRONG FAMILY
    // ==========================
    public void revokeFamily(String familyId) {
        List<RefreshToken> tokens =
                refreshTokenRepository.findByFamilyId(familyId);

        tokens.forEach(token -> token.setRevoked(true));

        refreshTokenRepository.saveAll(tokens);
    }
}

package com.example.security.service;

import com.example.security.dto.request.LoginResponse;
import com.example.security.dto.request.RefreshTokenRequest;
import com.example.security.dto.request.UserLogin;
import com.example.security.dto.request.UserRequest;
import com.example.security.entity.RefreshToken;
import com.example.security.entity.User;
import com.example.security.repository.UserRepo;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.security.authentication.AuthenticationManager;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.userdetails.UserDetails;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Service;

import java.util.UUID;

@Service
public class AuthService {

    @Autowired
    private UserRepo userRepo;

    @Autowired
    private AuthenticationManager authenticationManager;

    @Autowired
    private PasswordEncoder passwordEncoder;

    @Autowired
    private RefreshTokenService refreshTokenService;

    @Autowired
    private JwtService jwtService;

    @Autowired
    private CustomUserDetailsService userDetailsService;

    // ==========================================
    // ĐĂNG KÝ
    // ==========================================
    public void createUser(UserRequest userRequest) {
        User newUser = new User();

        newUser.setUsername(userRequest.getUsername());

        String passwordEncrypted =
                passwordEncoder.encode(userRequest.getPassword());
        newUser.setPassword(passwordEncrypted);

        newUser.setRole(userRequest.getRole());
        newUser.setEnabled(true);

        userRepo.save(newUser);
    }

    // ==========================================
    // LOGIN: Access + Refresh + Family
    // ==========================================
    public LoginResponse login(UserLogin userLogin) {

        Authentication authentication = authenticationManager.authenticate(
                new UsernamePasswordAuthenticationToken(
                        userLogin.getUsername(),
                        userLogin.getPassword()
                )
        );

        UserDetails userDetails = (UserDetails) authentication.getPrincipal();

        // TẠO TOKEN FAMILY MỚI KHI LOGIN
        String familyId = UUID.randomUUID().toString();

        // Access Token
        String accessToken = jwtService.generateToken(userDetails);

        // Refresh Token
        String refreshToken = jwtService.generateRefreshToken(userDetails);

        // Lưu Refresh Token + Family vào DB
        refreshTokenService.save(
                refreshToken,
                userDetails.getUsername(),
                familyId
        );

        return new LoginResponse(accessToken, refreshToken);
    }

    // ==========================================
    // REFRESH: Rotation + Reuse Detection + Token Family
    // ==========================================
    public LoginResponse refreshToken(RefreshTokenRequest request) {

        // 1. Lấy Refresh Token từ request
        String token = request.getRefreshToken();

        // 2. Tìm Refresh Token trong DB
        RefreshToken refreshToken = refreshTokenService.findByToken(token);

        // 3. Kiểm tra Token đã bị revoke chưa (Reuse Detection)
        if (refreshToken.isRevoked()) {

            String familyId = refreshToken.getFamilyId();

            // Reuse detected → revoke toàn bộ Family
            refreshTokenService.revokeFamily(familyId);

            throw new RuntimeException("Refresh token reuse detected");
        }

        // 4. Kiểm tra hết hạn
        refreshTokenService.verifyExpiration(refreshToken);

        // 5. Lấy familyId hiện tại (giữ nguyên khi rotation)
        String familyId = refreshToken.getFamilyId();

        // 6. Lấy username
        String username = refreshToken.getUsername();

        // 7. Load UserDetails
        UserDetails userDetails =
                userDetailsService.loadUserByUsername(username);

        // 8. Tạo Access Token mới
        String accessToken = jwtService.generateToken(userDetails);

        // 9. Tạo Refresh Token mới
        String newRefreshToken =
                jwtService.generateRefreshToken(userDetails);

        // 10. Vô hiệu hóa Refresh Token cũ
        refreshTokenService.revoke(refreshToken);

        // 11. Lưu Refresh Token mới (GIỮ NGUYÊN familyId)
        refreshTokenService.save(
                newRefreshToken,
                userDetails.getUsername(),
                familyId
        );

        // 12. Trả Token mới cho Client
        return new LoginResponse(accessToken, newRefreshToken);
    }
}

// =====================================================
// 1. GỌI API BÌNH THƯỜNG
// =====================================================

async function apiFetch(url, options = {}) {

    // Lấy Access Token
    const accessToken =
        localStorage.getItem("accessToken");


    // Tạo headers
    const headers = {
        "Content-Type": "application/json",
        ...options.headers
    };


    // Nếu có Access Token
    // thì thêm Authorization
    if (accessToken) {
        headers.Authorization =
            `Bearer ${accessToken}`;
    }


    // Gọi API
    let response = await fetch(
        API_URL + url,
        {
            ...options,
            headers: headers
        }
    );


    // =================================================
    // 2. ACCESS TOKEN HẾT HẠN
    // =================================================

    if (response.status === 401) {

        console.log("Access Token hết hạn");

        // Thử Refresh Token
        const refreshed =
            await refreshAccessToken();


        // =============================================
        // 3. REFRESH THÀNH CÔNG
        // =============================================

        if (refreshed) {

            console.log(
                "Refresh Access Token thành công"
            );


            // Lấy Access Token mới
            const newAccessToken =
                localStorage.getItem("accessToken");


            // Cập nhật Authorization
            headers.Authorization =
                `Bearer ${newAccessToken}`;


            // =========================================
            // 4. RETRY REQUEST CŨ
            // =========================================

            response = await fetch(
                API_URL + url,
                {
                    ...options,
                    headers: headers
                }
            );

            return response;
        }


        // =============================================
        // 5. REFRESH THẤT BẠI
        // =============================================

        console.log(
            "Refresh Token không hợp lệ"
        );


        logout();

        return response;
    }


    // Response bình thường
    return response;
}



// =====================================================
// 6. REFRESH ACCESS TOKEN
// =====================================================

async function refreshAccessToken() {

    // Lấy Refresh Token hiện tại
    const refreshToken =
        localStorage.getItem("refreshToken");


    // Không có Refresh Token
    if (!refreshToken) {

        console.log(
            "Không có Refresh Token"
        );

        return false;
    }


    try {

        // Gọi Backend
        const response = await fetch(
            API_URL + "/api/auth/refresh",
            {
                method: "POST",

                headers: {
                    "Content-Type": "application/json"
                },

                body: JSON.stringify({
                    refreshToken: refreshToken
                })
            }
        );


        // Refresh thất bại
        if (!response.ok) {

            console.log(
                "Refresh Token hết hạn hoặc không hợp lệ"
            );

            return false;
        }


        // Lấy dữ liệu Backend trả về
        const data =
            await response.json();


        // =============================================
        // 7. LƯU TOKEN MỚI
        // =============================================

        localStorage.setItem(
            "accessToken",
            data.accessToken
        );


        // Vì Backend đang sử dụng
        // Refresh Token Rotation
        // nên phải lưu cả Refresh Token mới
        localStorage.setItem(
            "refreshToken",
            data.refreshToken
        );


        return true;

    } catch (error) {

        console.error(
            "Lỗi khi refresh token:",
            error
        );

        return false;
    }
}



// =====================================================
// 8. LOGOUT
// =====================================================

function logout() {

    // Xóa Access Token
    localStorage.removeItem(
        "accessToken"
    );


    // Xóa Refresh Token
    localStorage.removeItem(
        "refreshToken"
    );


    // Đưa người dùng về Login
    window.location.href =
        "login.html";
}

Đây là file quan trọng nhất – xử lý toàn bộ logic Refresh Token.

JavaScript
import axios from "axios";

const axiosClient = axios.create({
    baseURL: "http://localhost:8080",
    headers: {
        "Content-Type": "application/json"
    }
});


// =====================================================
// REQUEST INTERCEPTOR
// Tự động thêm Access Token
// =====================================================

axiosClient.interceptors.request.use(
    (config) => {

        const accessToken =
            localStorage.getItem("accessToken");

        if (accessToken) {
            config.headers.Authorization =
                `Bearer ${accessToken}`;
        }

        return config;
    },

    (error) => {
        return Promise.reject(error);
    }
);


// =====================================================
// RESPONSE INTERCEPTOR
// Xử lý 401
// =====================================================

axiosClient.interceptors.response.use(

    // Response bình thường
    (response) => {
        return response;
    },

    // Response lỗi
    async (error) => {

        const originalRequest = error.config;


        // Kiểm tra 401
        if (
            error.response?.status === 401 &&
            !originalRequest._retry
        ) {

            originalRequest._retry = true;


            // Lấy Refresh Token
            const refreshToken =
                localStorage.getItem("refreshToken");


            // Không có Refresh Token
            if (!refreshToken) {
                logout();
                return Promise.reject(error);
            }


            try {

                // =========================================
                // GỌI /api/auth/refresh
                // =========================================

                const response = await axios.post(
                    "http://localhost:8080/api/auth/refresh",
                    {
                        refreshToken: refreshToken
                    }
                );


                const newAccessToken =
                    response.data.accessToken;

                const newRefreshToken =
                    response.data.refreshToken;


                // =========================================
                // LƯU TOKEN MỚI
                // =========================================

                localStorage.setItem(
                    "accessToken",
                    newAccessToken
                );

                localStorage.setItem(
                    "refreshToken",
                    newRefreshToken
                );


                // =========================================
                // CẬP NHẬT REQUEST CŨ
                // =========================================

                originalRequest.headers.Authorization =
                    `Bearer ${newAccessToken}`;


                // =========================================
                // RETRY REQUEST CŨ
                // =========================================

                return axiosClient(originalRequest);

            } catch (refreshError) {

                console.log(
                    "Refresh Token thất bại"
                );

                logout();

                return Promise.reject(
                    refreshError
                );
            }
        }


        return Promise.reject(error);
    }
);


// =====================================================
// LOGOUT
// =====================================================

function logout() {

    localStorage.removeItem("accessToken");
    localStorage.removeItem("refreshToken");

    window.location.href = "/login";
}


export default axiosClient;
